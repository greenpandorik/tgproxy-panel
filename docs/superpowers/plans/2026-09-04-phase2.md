### Task 22: Four more presets and deterministic uniquification

**Interfaces:**
- `sitekit.Uniquify(b Bundle, seed string) (Bundle, error)`: deterministic for (b, seed); different seeds produce different HTML and different asset file names; identical (b, seed) → identical Hash.
  Transformations, all seed-driven (`rand.New(rand.NewSource(int64(binary.LittleEndian.Uint64(sha256(seed)[:8]))))`):
  1. Shuffle direct children of `<main>` that carry `data-block` (keep any element without `data-block` in place; shuffle only among the movable ones' positions).
  2. Rename every class name that appears in both the HTML and the bundle's CSS files to `c<6 hex>` (consistent mapping across HTML and CSS; skip classes not found in any CSS to avoid breaking external semantics).
  3. For elements with `data-variants="a|b|c"`, pick one variant for the text content and remove the attribute.
  4. Rename `.css`/`.js` asset files to `<prefix>-<8 hex>.<ext>` and rewrite references in `<link href>`/`<script src>`.
  5. Strip all `data-block` and `data-variants` attributes from the output.
- Presets: each ~120–160 lines, one `<style>` block, `<main>` with 4–6 `data-block` sections, at least three `data-variants` texts, no forms/images/scripts/external resources, visually distinct layouts: blog (list of posts, sidebar), product landing (hero, features grid, pricing table with 3 tiers, FAQ), portfolio (masonry-like grid via CSS columns, about, contact), docs (left nav + article with headings, code blocks styled). Each must pass `Normalize` with zero errors.

```go
func TestEveryMutatingRouteIsProtected(t *testing.T) {
	h := apitest.New(t)
	h.CreateAdmin("v", "pass-123456", "viewer")
	viewer := h.Login("v", "pass-123456")
	anon := h.Anonymous()
	allowedForViewer := map[string]bool{"POST /api/v1/auth/logout": true, "POST /api/v1/me/password": true}
	publicMutations := map[string]bool{"POST /api/v1/auth/login": true, "POST /api/v1/install/{token}/register": true}
	router := h.Router() // apitest exposes the chi.Router used by the server
	_ = chi.Walk(router, func(method, route string, _ http.Handler, _ ...func(http.Handler) http.Handler) error {
		if method == "GET" || method == "HEAD" || method == "OPTIONS" || !strings.HasPrefix(route, "/api/v1/") { return nil }
		key := method + " " + route
		if publicMutations[key] { return nil }
		path := strings.NewReplacer("{id}", uuid.New().String(), "{node}", uuid.New().String(), "{token}", "x", "{file}", "x").Replace(route)
		if resp := anon.Do(method, path, map[string]any{}); resp.StatusCode != 401 { t.Errorf("%s: anonymous got %d, want 401", key, resp.StatusCode) }
		viewer.SendCSRF = false
		if resp := viewer.Do(method, path, map[string]any{}); resp.StatusCode != 403 { t.Errorf("%s: no-csrf got %d, want 403", key, resp.StatusCode) }
		viewer.SendCSRF = true
		if !allowedForViewer[key] {
			if resp := viewer.Do(method, path, map[string]any{}); resp.StatusCode != 403 { t.Errorf("%s: viewer got %d, want 403", key, resp.StatusCode) }
		}
		return nil
	})
}
```
