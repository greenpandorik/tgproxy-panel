# UI redesign — visual language v2

Дата: 2026-09-05. Утверждено заказчиком по макетам (`login-a`, `dash`).

## Цель
Убрать «шаблонный» вид: карточки с цветными полосами, иконка-буква в квадрате, центрированная карточка логина, крупные скругления и тени. Перейти к языку сильных админок (Linear, Vercel, Supabase, Grafana): почти чёрные нейтральные поверхности, волосяные границы, один нейтральный акцент, моноширинный шрифт для технических значений, плотные таблицы.

## Токены (dark по умолчанию; light — зеркальные значения)
- Поверхности: `--bg #09090b`, `--bg-2 #0f0f11` (панели), `--bg-3 #151517` (hover/active), light: `#fafafa / #ffffff / #f1f1f3`.
- Линии: `--line rgba(255,255,255,.07)`, `--line-2 rgba(255,255,255,.12)`; light: `rgba(0,0,0,.08) / .14`.
- Текст: `--fg #f4f4f5`, `--mute #8b8d93`, `--dim #55575f`; light: `#111113 / #6b6d75 / #9a9ca3`.
- Статусы: ok `#22c55e`, warn `#f59e0b`, err `#ef4444`, info `#3b82f6`. Только для статусов и графиков.
- Бренд: `--brand-primary` (из BrandingConfig) используется для активного пункта меню, фокус-кольца, ссылок и графиков; главная кнопка — `--fg` на `--bg` (нейтральная). `--brand-accent` — вторая серия графиков.
- Радиусы: 6px контролы, 8px панели, 4px теги. Тени: нет (кроме поповеров: `0 8px 24px rgba(0,0,0,.4)`).
- Шрифты: Inter (`@fontsource-variable/inter`), JetBrains Mono (`@fontsource-variable/jetbrains-mono`); base 13px/1.45; заголовок страницы 18px/600; tabular-nums везде для чисел.
- Плотность: строки таблиц 36px, паддинги панелей 16px, сайдбар 224px.

## Правила
- Хосты, ID, версии, секреты, размеры, времена — моноширинный шрифт (`.mono`), числа выровнены вправо.
- Таблицы: волосяные линии между строками, без полос, липкий заголовок, hover `--bg-3`, чекбоксы слева, bulk-панель появляется над таблицей.
- Стат-плитки: без цветных границ и иконок-акцентов; подпись 12px `--mute`, число 26px/600, строка контекста 11.5px mono `--dim`, дельта цветом статуса.
- Статус — точка 7px + текст, не заливка.
- Кнопки: primary = белая (`--fg`) с тёмным текстом; secondary = hairline outline; ghost — без рамки; destructive — красный текст outline, заливка только в confirm.
- Сайдбар: группы «Обзор / Инфраструктура / Доступ / Система» с подписями 10.5px uppercase; пункт 13px; активный — фон `--bg-3`, текст `--fg`, левая метка 2px цвета бренда; счётчики справа mono; футер: пользователь · роль, `api ok · db ok · время`.
- Топбар 48px: хлебные крошки mono-dim, поле «Поиск, команды… ⌘K», быстрые действия справа.
- Командная палитра (⌘K, cmdk): навигация по разделам, поиск нод и ключей по имени/хосту/лейблу, действия «Создать ключ», «Применить всё», «Сменить тему», «Сменить язык».
- Логин (вариант A): сплит 1fr / 520px. Слева: сетка-паттерн с радиальной маской, wordmark, карточка «Состояние сети» ТОЛЬКО с публичными данными (`GET /api/v1/status/public` → `{version, nodes_total, nodes_online, relay_commit}`), без хостов и имён; футер `vX · api ok · N нод`. Справа: заголовок «Вход», подзаголовок, поля, белая кнопка «Войти ↵», строка `ru · en` / год. Шаг 2FA — та же правая колонка.
- Диалоги/дроверы: заголовок 15px/600, hairline-разделители, кнопки справа, без цветных шапок.
- Пустые состояния: одна строка mute + одна кнопка. Скелетоны 8% белого.
- Никаких градиентных заливок, кроме радиальной подсветки на логине (≤10% альфы).
- Адаптив без изменений: карточки < 768px, drawer < 1024px.

## Не меняем
API, роуты, i18n-ключи (добавляются новые для палитры и логина), поведение форм и валидация.
