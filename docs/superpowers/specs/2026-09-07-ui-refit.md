# UI refit (phase 8) — design contract

Дата: 2026-09-07. Запрос заказчика: «переделай весь фронтенд панели», используя скилл
`design-taste-frontend` (`.agents/skills/design-taste-frontend/SKILL.md`, обязателен к прочтению).

## Design read

Reading this as: **redesign of an operator product UI (dashboard + data tables + forms) for
technical operators, with a near-black Linear-style language, leaning toward the existing
Tailwind v4 + shadcn/base-ui foundation, evolved rather than replaced.**

Скилл в своей шапке прямо исключает dashboards/data tables/product UI, а его раздел 11.E при
здоровой IA и существующей дизайн-системе предписывает targeted evolution, а не снос. Поэтому
берём из скилла то, что применимо к продуктовому UI (разделы 4.1, 4.2, 4.4, 4.5, 4.6, 6, 8, 9,
11), и не тащим правила лендингов (герой, бенто, eyebrow-лимиты, зигзаги, логотипные стены).

Dials (раздел 1, режим «Redesign — overhaul» по визуалу при сохранении IA):
`DESIGN_VARIANCE 5` · `MOTION_INTENSITY 4` · `VISUAL_DENSITY 6`.

## Что меняем

### 1. Типографическая шкала (Lever 1)
Токены в `index.css` + утилиты Tailwind. Ни одного `text-[Npx]` в `src/**` после рефита.

| Роль | Токен | Размер / высота / трекинг | Где |
|---|---|---|---|
| `display` | `--t-display` | 26/30, -0.02em, 600 | Заголовок страницы, число в KPI |
| `title` | `--t-title` | 17/24, -0.01em, 600 | Заголовки панелей, диалогов |
| `body` | `--t-body` | 14/21, 0 | Основной текст, поля, пункты меню |
| `label` | `--t-label` | 12.5/16, 0 | Подписи полей, вторичный текст |
| `micro` | `--t-micro` | 11/14, 0.04em, uppercase | Шапки таблиц, чипы, служебные метки |
| `mono` | `--t-mono` | 12.5/18, 0 | Хосты, id, версии, секреты, числа |

Правила: одна страница = один `display`. Шапки таблиц — `micro`. Числа и всё машинное — `mono`.
Никакого uppercase-трекинга вне `micro`.

### 2. Шкала радиусов (shape lock, 4.4)
Одно правило, записанное здесь и соблюдаемое везде:

* `--r-control: 8px` — кнопки, поля, селекты, чипы, вкладки, пункты меню.
* `--r-surface: 12px` — панели, карточки, диалоги, поповеры, шторки.
* `--r-pill: 9999px` — только точки статуса, аватар и счётчики-пилюли.
* `0` — строки таблиц и разделители.

Разовые пиксельные радиусы запрещены.

### 3. Плотность и ритм (Lever 2)
Вертикальный ритм кратен 4. Панель: заголовок `px-4 py-3`, тело `p-4`, между панелями `gap-4`.
Строка таблицы `h-11`, шапка `h-9`. Страница: `py-6`, между блоками `space-y-6`.
Таблицы остаются плотными, дышат заголовки и пустые состояния.

### 4. Цвет (Lever 3)
Палитра не меняется. Проверяем `COLOR CONSISTENCY LOCK`: бренд только для активного состояния,
фокуса, ссылок и первой серии графиков; статусы только для состояний; ничего декоративного.

### 5. Движение (Lever 4, MOTION_INTENSITY 4)
Без библиотек анимации, только CSS. Токены `--ease-out: cubic-bezier(0.2, 0, 0, 1)`,
`--dur-fast: 120ms`, `--dur-base: 180ms`.

* Тактильность (4.5): у каждой кнопки и кликабельной строки `:active` даёт `scale-[0.985]`.
* Наведение: только цвет и линия, без сдвигов раскладки.
* Вход панелей и строк: `fade+2px` подъём, задержка не более 40 мс на элемент, максимум 6 элементов.
* Всё внутри `@media (prefers-reduced-motion: reduce)` отключается (6.B).

### 6. Состояния (4.5, 4.6)
У каждого списка: загрузка (скелетон формой результата), пусто (что это и как заполнить),
ошибка (текст + повтор). Подпись над полем, ошибка под полем, плейсхолдер не заменяет подпись.

## Что не трогаем (11.C, 11.F)

Маршруты и слаги, названия пунктов навигации, ключи i18n и тексты, имена полей форм, состав и
порядок колонок, брендовые токены и знак, контракты API, тесты поведения. Правки только
визуальные; поведение и разметка меняются лишь там, где этого требует шкала.

## Приёмка

`npm run typecheck && lint && test -- --run && i18n:check && build`; ноль `text-[Npx]` и
разовых радиусов в `src/**`; светлая и тёмная темы проверены (8.D); контраст кнопок и полей
AA (4.5); мобильная раскладка объявлена в каждом многоколоночном блоке; скриншоты обновлены.
