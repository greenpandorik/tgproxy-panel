# С нуля: от аренды сервера до первой ссылки

[English](start.en.md) · **Русский**

Этот гид для тех, кто ни разу не арендовал сервер. Мы пройдём весь путь по шагам: арендуем
два сервера, купим домен, поставим панель и отправим другу ссылку на свой прокси для Telegram.
Если какое-то слово непонятно, загляните в [словарик](#словарик) в конце.

Уметь программировать не нужно. Понадобится компьютер с Windows 10 или новее либо с macOS,
банковская карта для оплаты сервера и домена и около часа времени. Большая часть этого часа
уйдёт на ожидание, пока домен начнёт работать.

## Как это устроено

Понадобятся два сервера. На первом работает панель: сайт, куда вы заходите из браузера и
управляете всем остальным. На втором работает сам прокси, через который люди подключаются к
Telegram. Панель настраивает прокси-сервер сама, заходить на него нужно только для установки
и обновлений.

```
Вы, браузер ──────────> Панель (сервер 1)
                            │ настраивает
                            ▼
Друзья, Telegram ─────> Прокси (сервер 2) ─────> Telegram
```

Прокси-серверов можно подключить сколько угодно, например в разных странах. Начнём с одного.

## 1. Арендуйте два сервера

Сервер, который сдают в аренду, называется VPS: это компьютер в дата-центре, которым вы
управляете через интернет. Его предлагают почти все хостинги, ищите «VPS» или «виртуальный
сервер». Самые простые VPS стоят несколько долларов в месяц, и для панели и прокси их хватает.

При заказе выберите для обоих серверов:

- операционную систему Ubuntu 24.04 или 22.04 (подойдёт и Debian 12);
- архитектуру x86_64, её ещё называют amd64 или просто x86. Серверы на ARM для прокси не
  подойдут;
- публичный IPv4-адрес. Обычно он входит в тариф;
- самый простой тариф: 1 процессор и 1 ГБ памяти.

Прокси-сервер арендуйте в стране, где Telegram работает без ограничений. Сервер для панели
может стоять где угодно.

После оплаты хостинг покажет в личном кабинете или пришлёт письмом IP-адрес сервера (четыре
числа через точку, например `203.0.113.10`) и пароль пользователя root. Запишите IP-адреса
обоих серверов и отметьте, какой из них для панели, а какой для прокси.

## 2. Купите домен и направьте его на серверы

Домен — это имя сайта, например `example.com`. Его покупают у регистратора доменов, их тоже
легко найти поиском. Простые домены стоят от пары долларов в год.

Для панели и прокси нужны отдельные имена. Их удобно сделать поддоменами одного домена:
например, `panel.example.com` для панели и `proxy1.example.com` для прокси.

> Лучше взять для прокси отдельный домен, не связанный с панелью. Сертификаты сайтов
> публикуются в открытых журналах, и по одному домену легко найти все его поддомены. Если
> рядом с прокси окажется страница входа в панель, прокси проще опознать. Для первого знакомства
> хватит и одного домена, а для серьёзной работы купите второй.

Теперь нужно сказать интернету, какой IP-адрес стоит за каждым именем. Для этого у домена
есть настройки DNS, а в них записи типа A. Откройте у регистратора раздел «DNS», «Управление
DNS» или «DNS-записи» и добавьте две записи:

| Тип | Имя (хост) | Значение |
|---|---|---|
| A | `panel` | IP-адрес сервера для панели |
| A | `proxy1` | IP-адрес сервера для прокси |

В поле «Имя» пишут только начало, без самого домена: регистратор сам допишет `.example.com`.

Новые записи начинают работать через несколько минут, иногда через пару часов. Проверить можно
с вашего компьютера. На Windows откройте «Терминал» (правой кнопкой по кнопке «Пуск» →
«Терминал»), на macOS программу «Терминал» и выполните:

```
nslookup panel.example.com
```

Если в ответе в строке `Address` стоит IP вашего сервера, запись работает. Проверьте так же
`proxy1.example.com`. Пока записи не заработали, ставить ничего не нужно: установщики проверяют
их первым делом и остановятся.

## 3. Откройте порты

У части хостингов в личном кабинете есть сетевой фильтр: он называется «Firewall», «Файрвол»
или «Группы безопасности». Если он есть и включён, разрешите в нём входящие подключения по TCP:

- на сервере панели: порты 22, 80 и 443;
- на прокси-сервере: порты 22, 80, 443 и 8443.

Порт 22 нужен, чтобы вы могли зайти на сервер, 80 и 443 для сайта и сертификата, 8443 для
Fake-TLS-ссылок. Если такого раздела в кабинете нет, ничего делать не нужно.

## 4. Подключитесь к серверу

С сервером работают через SSH: вы вводите команды в терминале на своём компьютере, а
выполняются они на сервере. Ничего устанавливать для этого не нужно, SSH уже есть в Windows 10
и новее и в macOS.

Откройте терминал так же, как в шаге 2, и введите `ssh root@` и IP-адрес сервера для панели:

```
ssh root@203.0.113.10
```

При первом подключении терминал спросит, доверяете ли вы этому серверу
(`Are you sure you want to continue connecting`). Напишите `yes` и нажмите Enter. Затем введите
пароль root из письма хостинга. Символы при вводе пароля не отображаются, так и должно быть:
просто наберите его и нажмите Enter.

Если в строке появилось что-то вроде `root@имя-сервера:~#`, вы на сервере. Команды в него
удобнее вставлять, чем набирать: скопируйте команду из инструкции и вставьте в терминал через
Ctrl+V или правой кнопкой мыши на Windows, через Cmd+V на macOS. Выйти с сервера можно командой
`exit`.

Если хостинг выдал не root, а другого пользователя, например `ubuntu`, подключайтесь как
`ssh ubuntu@203.0.113.10`. Команды установки ниже начинаются с `sudo`, так что сработают и так.

## 5. Поставьте панель

Подключитесь к серверу для панели и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/greenpandorik/tgproxy-panel/main/install.sh | sudo bash
```

Установщик задаст несколько вопросов на английском:

| Вопрос | Что ответить |
|---|---|
| `Panel domain` | Имя панели из шага 2, например `panel.example.com` |
| `E-mail for Let's Encrypt` | Ваш e-mail. На него придёт письмо, если с сертификатом сайта что-то пойдёт не так |
| `Admin username` | Логин для входа в панель. Нажмите Enter, чтобы оставить `admin` |
| `Admin password` | Пароль от 10 символов, он не отображается при вводе. Установщик попросит повторить его. Можно просто нажать Enter, тогда он придумает пароль сам |

Дальше установщик всё сделает сам: проверит, что домен ведёт на этот сервер и порты свободны,
поставит нужные программы и получит сертификат для сайта. Это займёт несколько минут. Если
проверка не пройдёт, он объяснит, в чём дело, и предложит повторить (`r`), продолжить (`c`) или
выйти (`q`). Обычно достаточно подождать, пока заработает DNS-запись, и нажать `r`.

В конце установщик напечатает адрес панели и, если вы не задавали пароль, сгенерированный
пароль. Он показывается один раз, сохраните его сразу.

Откройте в браузере адрес панели, например `https://panel.example.com`, и войдите.

Советуем сразу включить двухфакторный вход: тогда для входа в панель кроме пароля понадобится
код из приложения на телефоне. Откройте меню пользователя в правом верхнем углу → «Пароль и 2FA»
и нажмите «Включить». Панель покажет QR-код для приложения-аутентификатора и
резервные коды: сохраните их, без них при потере телефона в панель не войти.

## 6. Подключите прокси-сервер

В панели откройте «Серверы» и нажмите «Добавить сервер». Заполните три поля:

- «Имя» — как сервер будет называться в панели, например «Амстердам»;
- «Хост» — имя прокси из шага 2, например `proxy1.example.com`;
- «E-mail для Let's Encrypt» — ваш e-mail.

Остальные поля оставьте как есть и нажмите «Создать сервер». Панель покажет команду установки.
Она одноразовая и действует 24 часа. Скопируйте её кнопкой рядом с командой.

Не закрывайте окно панели. Откройте второй терминал, подключитесь к прокси-серверу, как в
шаге 4, и вставьте команду. Установщик проверит DNS, порты и сервер, поставит прокси и
получит сертификат. Через пару минут окно в панели сменится на «Агент подключён», а сервер
появится в списке с зелёной точкой.

## 7. Выдайте первый ключ

Ключ — это доступ к прокси для одного человека или для группы. Откройте «Ключи доступа» и
нажмите «Новый ключ». На вкладке «Личный» заполните:

- «Название ключа» — чтобы потом найти его в списке, например «Анна, телефон»;
- «Кому выдан» — имя человека или его e-mail;
- «Серверы» — отметьте свой прокси-сервер.

Нажмите «Создать ключ». Панель покажет ссылки и QR-коды. Ключ заработает меньше чем через
минуту, когда панель отправит его на сервер.

У каждого ключа две ссылки, они переключаются вкладками:

- Fake-TLS работает во всех приложениях Telegram. Если сомневаетесь, отправляйте её.
- WEB-прокси труднее заблокировать, но пока он работает только в Telegram Desktop и новых
  версиях Telegram для Android.

## 8. Подключитесь из Telegram

Отправьте ссылку человеку в любом мессенджере или покажите QR-код. Когда он откроет ссылку
на устройстве с Telegram или отсканирует QR камерой телефона, Telegram предложит подключить
прокси. Остаётся нажать «Подключить».

Проверьте сами: откройте ссылку на своём телефоне. В мобильном Telegram подключённый прокси
виден в настройках, в разделе «Данные и память» → «Прокси».

Готово: у вас есть своя панель и свой прокси.

## Что дальше

Сохраните копию файла с секретами панели. В нём лежит мастер-ключ, которым зашифрованы секреты
ключей в базе: без него их не восстановить даже из резервной копии. Если вы подключались как
root, выполните на своём компьютере, а не на сервере:

```
scp root@203.0.113.10:/opt/tgproxy-panel/.env ./tgproxy-panel.env
```

Файл `tgproxy-panel.env` появится в папке, где открыт терминал. Храните его в надёжном месте и
никому не показывайте.

Включите резервные копии базы: «Настройки» → «Резервные копии».

Обновляйте панель командой на её сервере:

```bash
sudo /opt/tgproxy-panel/install.sh --update
```

а прокси-сервер командой на нём самом:

```bash
sudo tgwp-agent upgrade
```

Если что-то не работает, откройте сервер в панели и вкладку «Проверки»: «Полная проверка
сервера» покажет, что не так. Подробности об установке есть в [полной инструкции](setup.ru.md),
а вопросы можно задать в [Обсуждениях](https://github.com/greenpandorik/tgproxy-panel/discussions).

## Словарик

| Слово | Что это |
|---|---|
| VPS | Сервер, который вы арендуете у хостинга. Работает круглосуточно в дата-центре, а вы управляете им через интернет. |
| IP-адрес | Номер сервера в интернете, например `203.0.113.10`. |
| Домен | Имя сайта вместо IP-адреса, например `example.com`. Поддомен — имя внутри домена, например `panel.example.com`. |
| DNS и A-запись | DNS — справочник интернета, который по имени находит IP-адрес. A-запись в нём говорит: «имя `panel.example.com` — это сервер `203.0.113.10`». |
| Порт | Номер «двери» на сервере. Разные программы принимают подключения на разных портах: сайт на 443, SSH на 22. |
| SSH и терминал | Терминал — окно, в котором вводят команды. SSH — способ выполнять эти команды на удалённом сервере. |
| root | Главный пользователь сервера, которому разрешено всё. Установка требует его прав. |
| Сертификат | То, что позволяет сайту работать по `https://`. Панель и прокси получают его сами, бесплатно, у Let's Encrypt. |
| MTProxy | Прокси, который Telegram понимает сам, без отдельных программ. Подключается по ссылке. |
| Fake-TLS | Вид MTProxy, который снаружи выглядит как обычный заход на сайт. |
| WEB-прокси | Новый вид прокси Telegram. Работает через обычный HTTPS на порту 443. |
| Сайт-прикрытие | Обычный сайт, который открывается на домене прокси. Посторонний, зашедший по адресу, увидит его, а не прокси. |
| Ключ | Доступ к прокси для одного человека или группы. У каждого ключа свои ссылки, и его можно отозвать, не трогая остальных. |
