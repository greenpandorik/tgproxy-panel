Как установить Telegram-прокси с telemt и TGProxy Panel

Установка TGProxy Panel и telemt на двух VPS: требования, DNS, порты, подключение сервера, первый пользователь и проверка Telegram.

Обновлено 8 октября 2026 · Документация открытого проекта

TGProxy Panel помогает управлять собственными Telegram-прокси: создавать пользователей, выдавать ссылки подписки, применять лимиты и проверять состояние серверов. Панель работает на одном VPS, а telemt — на отдельном прокси-сервере. Клиентский трафик проходит через telemt, а не через панель.

Что подготовить

Этот порядок рассчитан на установку с доменами и HTTPS. Если вы впервые арендуете VPS, начните с инструкции «С нуля».

ПараметрСервер панелиПрокси-сервер
СистемаUbuntu 22.04+ или Debian 12+Ubuntu 22.04+ или Debian 12+, x86_64
РесурсыОт 1 CPU и 1 ГБ RAMОт 1 CPU и 1 ГБ RAM; размер зависит от нагрузки
АдресДомен с A-записью на VPSПубличный IPv4 и отдельный домен с A-записью
Входящие TCP-порты22, 80, 44322, 80, 443 и порт Fake-TLS — по умолчанию 8443

Порты 80 и 443 должны быть свободны до установки. Разрешите их в файрволе VPS и сетевом фильтре хостинга: установщик сам порты не открывает. Прокси-серверу нужен исходящий доступ к панели, GitHub и датацентрам Telegram. Проверьте, что DNS уже указывает на нужные серверы.

1. Установите панель

Подключитесь по SSH к серверу панели и выполните команду с правами root. Она загружает установщик из официального репозитория; перед запуском можно прочитать его код.

curl -fsSL https://raw.githubusercontent.com/greenpandorik/tgproxy-panel/main/install.sh | sudo bash

Укажите домен панели, e-mail для сертификата и данные администратора. Скрипт установит Docker при необходимости, запустит панель, PostgreSQL и Caddy. После завершения откройте выданный HTTPS-адрес и войдите в панель.

2. Подключите сервер с telemt

Откройте «Серверы → Добавить сервер». Укажите имя, домен прокси и e-mail. Для новой установки выберите telemt: он обслуживает Fake-TLS, WEB-прокси и сайт-прикрытие.

Панель выдаст команду с одноразовым токеном, действительным 24 часа. Выполните именно эту команду на прокси-сервере. Токен регистрации не публикуйте и не отправляйте посторонним. Установщик проверит DNS и порты, установит движок и агента, получит сертификат и зарегистрирует сервер после проверки готовности.

Дождитесь статуса «На связи». Если регистрация не завершилась, сохраните текст ошибки и откройте руководство по устранению неполадок.

3. Создайте пользователя и проверьте подключение

В разделе «Пользователи» создайте пользователя, назначьте срок доступа и прокси-сервер. Скопируйте ссылку подписки: она открывает страницу с инструкциями для устройства, Fake-TLS и WEB-ссылками.

Доступ начинает работать после применения настроек на сервере, обычно в течение минуты. Для первого теста откройте Fake-TLS-ссылку в Telegram и подтвердите подключение. Затем проверьте WEB, если ваш клиент поддерживает его. У каждого пользователя собственный секрет: для отзыва доступа используйте управление пользователем в панели.

4. Проверьте сервер и сохраните доступ к панели

На странице сервера запустите «Проверку с панели» и «Полную проверку сервера». Посмотрите DNS, сертификат, порты, состояние telemt и соединения с Telegram. Работоспособность из сети панели не гарантирует доступность у каждого провайдера — проверьте подключение с устройства пользователя.

Включите двухфакторный вход, настройте резервные копии и Telegram-уведомления. Для обновления панели используйте sudo /opt/tgproxy-panel/install.sh --update, для обновления агента и telemt — tgwp-agent upgrade. Команда использует версии, закреплённые панелью. Если нужно обновить только агент, используйте tgwp-agent upgrade --agent. Перед обновлением просмотрите план командой tgwp-agent upgrade --check.

Если Telegram не подключается

  • Проверьте, что сервер на связи и изменения пользователя уже применены.
  • Сверьте адрес и порт из ссылки; отдельно проверьте порт Fake-TLS в файрволе.
  • Проверьте срок доступа и лимит трафика пользователя.
  • Сравните подключение через мобильную сеть и Wi-Fi, затем Fake-TLS и WEB.
  • Проверьте маршрут прокси-сервера к Telegram. Запасной домен может помочь при блокировке основного имени, но не исправит остановленный движок или недоступный датацентр.

Детальные команды и проверяемые пути доступны в полной инструкции по установке. Для выбора транспорта прочитайте сравнение MTProxy, Fake-TLS и WEB.

Для автоматизации пользователей и серверов используйте API управления: персональные токены, права доступа и готовые примеры.
