Getting started

Portage keeps every project's dependencies in its own sandbox, switched automatically per directory.

Install

curl -fsSL https://get.portage.example | sh
portage init

Once installed, run portage init inside a project directory to create its sandbox.

Configuration

Settings live in a single portage.toml file at the project root.

[sandbox]
runtime = "node@20"
cache   = "shared"

[env]
PORT = "4000"

Values under [env] are only visible inside the sandbox, never exported to the host shell.

Commands

CommandWhat it does
portage initCreate a sandbox for the current directory
portage run <cmd>Run a command inside the sandbox
portage statusShow sandbox state and disk usage
portage removeDelete the sandbox for this directory

FAQ

Does it slow down builds?

No — the sandbox mounts the host filesystem directly, so builds run at native speed.

Can two projects share a runtime?

Yes, set cache = "shared" and matching runtimes reuse the same download.
